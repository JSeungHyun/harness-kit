# 장치 장부 — 무슨 결과로 넣었고, 언제 · 어떤 모델에서 쟀나

> 상태: **설계안** · 덜어내기의 입구다. 지침과 도구는 늘수록 문맥을 차지하고 서로 겹친다 — 효과가 확인되지 않은 것 · 모델이 바뀌어 필요 없어진 것을 이 표에서 찾아 끄고 다시 잰다. 설치에 가지 않는 문서다(질문당 0 · 세션 시작 0)

**읽는 법**

| 칸 | 뜻 |
|---|---|
| 장치 | 키트가 설치에 얹는 것 하나. 훅은 정책 파일과 그것이 띄우는 도구가 한 행이다 |
| 강제 방식 | exit 1 · 되돌림 · 차단 · 주입 · 글(모델의 기억에 맡김) |
| 근거 지표 | 결과 숫자와 출처 — `proof.md` 절 또는 `plan.md` 차수:줄(18차 합본 기준). 「불렀나」(준수율) · 합성 시험 · 쓰임 횟수뿐이면 그대로 적고 **결과 근거 없음** |
| 마지막 측정일 | 그 숫자를 마지막으로 잰 날 |
| 잰 모델 · 판 | 그 측정에서 돈 모델 · Claude Code 판. 기록에 없으면 「모름」, 모델이 안 도는 재생 · 합성이면 「LLM 없음」 |
| 질문당 비용 | 훅 시간 · 주입 글자 · 세션 시작 때 읽는 글자. 설치 · 측정 · 부를 때만 도는 것은 「질문당 0」 |
| 걷기 조건 | 이것이 나오면 뺀다 / 다시 잰다 |

- 행을 더하고 빼는 것은 `test/device-ledger.test.mjs` 가 지킨다 — 도구 · 훅 · 규칙 절 · 스킬 · 권한 묶음 · 장부 템플릿이 생기거나 사라지면 이 표가 같이 바뀌어야 한다
- 장부 밖: `lib/`(도구의 속) · `policy/recipes.json` · `policy/removed.json`(`detect` · `upgrade` 가 읽는 자료) · `templates/map/` · `templates/harness.json` · `templates/scan.json`(프로젝트가 채우는 골격)
- 측정값이 바뀌면 그 행을 그 자리에서 고친다. 모델이 바뀌면 「잰 모델」이 옛것인 행부터 다시 잰다
